# Ombre

Online store for **Ombre**, a square folding beach shade (50 × 50 cm, Beige and Blue), sold across Lebanon with cash on delivery.

## What's in this repo

| Folder | What it is |
|---|---|
| `preview/` | The clickable design preview: home, product, shop, about, cart, checkout, order confirmation and a preview **admin** (`#admin`). One static page, no build step. Orders and admin changes are saved in the visitor's browser only. |
| `store/` | The full store: Next.js + Supabase, with a real database, admin login, orders, stock, discounts and an editable website. See `store/README.md` for setup. |

## Open the preview

Open `preview/index.html` in a browser. The admin is not linked from the store: go to `preview/index.html#admin` and create a password the first time. From the admin, **Customize site** opens the Shopify-style theme editor (sections and blocks, theme settings, desktop and mobile preview, undo, draft and publish).
